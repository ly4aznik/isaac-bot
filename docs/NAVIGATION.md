# Навигация этапа 2

Lua экспортирует `grid` для каждого наблюдения:

- размеры и количество клеток;
- мировой origin и размер клетки (40 игровых единиц);
- `GridCollisionClass` каждой клетки.

Python считает проходимым `COLLISION_NONE = 0`. Ямы, объекты, твёрдые клетки и
стены блокируются. Начальная и целевая клетки при необходимости привязываются к
ближайшей проходимой клетке.

## Алгоритм

1. Мировые координаты переводятся в координаты сетки.
2. A* строит кратчайший четырёхсвязный путь с Manhattan heuristic.
3. Steering направляет непрерывные оси движения к следующему waypoint.
4. Достигнутые waypoint пропускаются.
5. Если за окно наблюдений игрок сдвинулся меньше порога, путь строится заново.
6. Для двери сначала достигается внутренняя точка подхода, затем контроллер
   движется через центр двери до изменения `room_index`.

## Команды

```powershell
python run_bot.py navigate-point --x 320 --y 280
python run_bot.py navigate
python run_bot.py navigate --door 2
```

`navigate` без номера выбирает ближайшую открытую дверь. Успех прохода
подтверждается не временем или предполагаемой позицией, а фактической сменой
комнаты в Lua-телеметрии.

Для фоновой автономной работы в `options.ini` требуется
`PauseOnFocusLost=0`; иначе потеря фокуса останавливает игровые update callbacks
и вместе с ними обработку UDP.
